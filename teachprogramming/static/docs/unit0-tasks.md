Mini Tasks - to build programming fluency
==========

* Combine the basics of `function`s, `variable`s, `if`, `for`, `while`, arithmetic operators, relational operators.
* Learning to combine these foundations is super hard if you've never done it before.
* Try to keep all this work in a single file - each task should be in it's own function.
* Once you have completed each task - write the solution by hand in your book (This reinforcement feel weird, but it will really help).
* Good 'skill' (because luck wont help you).

Tasks
-----

1. Using for loop: Count from 0 to 10
2. Using while loop: Count from 0 to 10
3. Using for loop: Count down from 10 to -10
4. Using while loop: Count down from 10 to -10
5. Ask the user for 2 numbers - display the biggest number
6. Ask the user for 3 numbers and return the biggest number
7. Create a function that asks the user for 2 numbers and returns the biggest number
8. Create a function called `add` that takes two numbers (a and b) and returns: a added to b
9. Create a function called `addWith10` that takes two numbers (a and b) and returns: a added to b added to 10
10. Ask the user for 3 numbers and append them to list
11. Keep asking the user for numbers until they type "exit" and then:
    1. print all the numbers entered
    2. print the sum/total of all the numbers added together
    3. print the biggest number
